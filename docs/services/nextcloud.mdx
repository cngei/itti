# Nextcloud – File, documenti e moduli

## Cos'è

Nextcloud è come un disco rigido virtuale dove puoi salvare i tuoi file, documenti e molto altro. Puoi accederci da qualsiasi dispositivo: computer, tablet o telefono.

## A cosa serve

- Salvare e condividere documenti
- Lavorare insieme sullo stesso file
- Sincronizzare i file tra tutti i tuoi dispositivi
- Creare moduli per raccogliere informazioni

## Come si usa

### Primo accesso

1. Apri [cloud.cngei.it](https://cloud.cngei.it)
2. Accedi con le tue credenziali
3. Vedrai una schermata con i tuoi file e cartelle

### Caricare un file

1. Clicca sul pulsante **+** o **Carica**
2. Scegli il file dal tuo computer o telefono
3. Il file apparirà nella cartella in cui ti trovi

### Condividere un file

1. Clicca sui **tre puntini** accanto al file che vuoi condividere
2. Scegli **Condividi**
3. Inserisci il nome della persona con cui vuoi condividere
4. Scegli se la persona può solo leggere o anche modificare il file

### Creare un documento

1. Clicca sul pulsante **+**
2. Scegli il tipo di documento: **Documento di testo**, **Foglio di calcolo** o **Presentazione**
3. Dai un nome al documento e inizia a scrivere

### Sincronizzare sul computer

1. Chiedi all'amministratore come installare l'app di Nextcloud
2. Una volta installata, i tuoi file saranno sempre aggiornati su tutti i dispositivi

## Nextcloud Forms – Creare moduli

### Cos'è Forms

Forms è una funzione di Nextcloud che ti permette di creare moduli per raccogliere risposte, come iscrizioni, sondaggi o richieste di informazioni.

### Creare un nuovo modulo

1. Apri Nextcloud e clicca su **Forms** nel menu
2. Clicca su **Nuovo modulo**
3. Scrivi il titolo del modulo (es. "Iscrizione al campo")
4. Aggiungi una descrizione se serve

### Aggiungere domande

1. Clicca su **Nuova domanda**
2. Scegli il tipo di domanda:
   - **Risposta breve**: per nomi, email, numeri
   - **Risposta lunga**: per messaggi o commenti
   - **Scelta multipla**: quando ci sono opzioni predefinite
   - **Caselle di controllo**: quando si possono scegliere più opzioni
   - **Data**: per scegliere un giorno
3. Scrivi la domanda e le opzioni di risposta
4. Indica se la domanda è obbligatoria

### Condividere il modulo

1. Clicca su **Condividi** in alto a destra
2. Copia il link e invialo a chi deve compilare il modulo
3. Puoi anche condividere il modulo direttamente con utenti di Nextcloud

### Vedere le risposte

1. Torna al tuo modulo
2. Clicca sulla scheda **Risposte**
3. Vedrai un riepilogo di tutte le risposte ricevute
4. Puoi anche scaricare le risposte in un foglio di calcolo

### Suggerimenti per i moduli

- Usa domande chiare e semplici
- Non esagerare con il numero di domande
- Attiva la raccolta email se hai bisogno di sapere chi ha risposto
- Chiudi il modulo quando non servono più risposte
