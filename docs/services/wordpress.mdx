# WordPress – Siti web

## Cos'è

WordPress è uno strumento per creare e gestire siti web in modo semplice, senza bisogno di sapere programmare.

## A cosa serve

- Creare il sito web del gruppo o della sezione
- Pubblicare notizie e aggiornamenti
- Condividere informazioni con famiglie e soci
- Gestire pagine per eventi o attività specifiche

## Come richiedere un sito di sezione

Contattaci tramite [Help](https://help.cngei.it) indicando:

- Se vuoi usare Wordpress con il template nazionale
- Se vuoi installare un tuo CMS caricando il codice tramite FTP
- Se hai bisogno di un database

## Come si usa

### Accedere al sito

1. Apri [cngei.it](https://cngei.it)
2. Per modificare il sito della tua sezione, aggiungi `/wp-admin` alla fine del link (ad esempio `aosta.cngei.it/wp-admin`)
3. Accedi con le tue credenziali

### Scrivere un nuovo articolo

1. Nel menu a sinistra, clicca su **Articoli** → **Aggiungi nuovo**
2. Scrivi il titolo dell'articolo
3. Scrivi il contenuto nell'area grande
4. Per aggiungere immagini, clicca sul **+** e scegli **Immagine**
5. Quando hai finito, clicca su **Pubblica**

### Creare una nuova pagina

1. Nel menu a sinistra, clicca su **Pagine** → **Aggiungi nuova**
2. Scrivi il titolo e il contenuto
3. Le pagine sono per contenuti fissi (es. "Chi siamo", "Contatti")
4. Clicca su **Pubblica**

### Aggiungere un'immagine

1. Mentre scrivi un articolo o una pagina, clicca sul **+**
2. Scegli **Immagine**
3. Carica una nuova immagine o scegline una già presente
4. Aggiungi una descrizione per aiutare chi non può vederla

### Modificare il menu

1. Vai su **Aspetto** → **Menu**
2. Scegli quali pagine mostrare nel menu del sito
3. Salva le modifiche
