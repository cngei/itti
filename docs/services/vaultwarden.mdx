# Vaultwarden – Gestore password

## Cos'è

Vaultwarden è un servizio che ti permette di salvare tutte le tue password in un posto sicuro. Invece di ricordare decine di password diverse o scriverle su un foglio, puoi affidarti a Vaultwarden.

## A cosa serve

- Salvare le password dei siti che visiti
- Generare password difficili da indovinare
- Compilare automaticamente i moduli di accesso
- Condividere password in sicurezza con altri membri del gruppo

## Come si usa

### Primo accesso

1. Apri [password.cngei.it](https://password.cngei.it)
2. Inserisci la tua email e la password principale
3. Se è la prima volta, ti verrà chiesto di creare un account

### Salvare una nuova password

1. Quando accedi a un sito, Vaultwarden ti chiederà se vuoi salvare la password
2. Clicca su **Salva**
3. La password verrà memorizzata in modo sicuro

### Recuperare una password dimenticata

1. Apri Vaultwarden
2. Cerca il sito che ti interessa nella barra di ricerca
3. Clicca sul sito per vedere nome utente e password

### Generare una password sicura

1. Quando crei un nuovo account su un sito, Vaultwarden può creare una password per te
2. Clicca sul simbolo del **fulmine** o **genera password**
3. Scegli una password lunga almeno 12 caratteri

## Suggerimenti utili

- Usa una password principale molto forte e non dimenticarla
- Attiva la verifica in due passaggi se possibile
- Non condividere mai la tua password principale con nessuno

## Hai bisogno di aiuto?

Se hai problemi ad accedere o a salvare le password, contatta un amministratore del gruppo.
