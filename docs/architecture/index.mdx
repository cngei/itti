# Architettura dell'infrastruttura

Questa sezione descrive come è organizzata l'infrastruttura informatica del CNGEI, dai server fisici alla distribuzione dei servizi.

## Panoramica

L'infrastruttura è basata su un **cluster Kubernetes** gestito con **Talos Linux** e i servizi vengono distribuiti tramite **ArgoCD** usando un approccio GitOps. Tutta la configurazione è versionata nel repository [cngei-gitops](https://github.com/cngei/cngei-gitops).
